mN = 1. At mN = 0.1, where worlds stay diverse throughout, it rises over the run, 0.42 -> 0.57 -> 0.69 at 25 / 50 /

## The model can't express

- **Testers that do not take over.** Assumption A needs testers that visit and leave. In the island model a migrant
  that outscores the natives establishes and changes the profile (stage 1b: testers established in up to 1.2% of
  replicates and dragged the neutral control to 0.25-0.8). The migrant tier and colonization are the same event in
  this model; there is no way to test a program against a migrant without risking a takeover.
- **Arrival of on-path variants in proportion to their relevance.** The only on-path equivalents that reach an island
  are other islands' residents (by migration) or prior draws (by the tail, 0.3% after half the horizon). A variant
  that would do better against the migrants is usually never present (empty arrival sets in most cases). The
  statement "best response among variants" has no supply mechanism here except the prior, which is front-loaded.
- **Off-path testing within a consensus world.** At program consensus every migrant is a native, so the migrant tier
  has nothing to act on, and the prior tier acts only through founders and the decaying tail. A threat that is never
  executed cannot be selected against: costly threats are carried by 0.61 (T) and 1.00 (M) of zero-regret residents.
- **Regret against compositions in arm P under lumping.** The published arm P kernel merges classes identical on the
  current support; migrant regret against absent variants is undefined there (arm P was rerun without lumping).
- **Per-arrival bookkeeping in arm P.** The arm P kernel does not log which classes arrived on an island, so arm P's
  supply control is founder-weighted (an approximation).

## Deviations from the spec

1. Fitness is exp(w * payoff) in all three arms, so P10's w/f is w; stage 0 uses linear fitness with f = 1.
2. Stage 0a draws the testers met per birth event (Binomial(i, eps)) and simulates the embedded jump chain; it is
   compared with P10's finite-N formula (scored) and with the exact value of the realized process (reported).
3. Stage 0b: tester cases r_q in {0.7, 0.9, 1.0}, each indifferent to the variant (scored), plus r_q = 0.9 with
   +/-0.1 feedback (reported); 2 x 10^4 replicates per point; 20-generation burn-in of the partner slot.
4. Arm P was run with lumping off (same law, a different random stream); its environment was checked draw for draw
   with lumping on (35 of 35 runs: 5 per forced rival and 5 natural match the stored rows exactly). The published
   cells' headline (dense P* separated 0.97, island P(C,C) >= 0.978) is compared statistically below.
5. Arm P's middle dose is its published boundary mN = 1.091; stage-2 doses {0.1, 1.091, 3, 10}. Arm P's 50% and 75%
   states were not saved (route (b) there uses the kernel's strong-holder log). Arm P's stage 2 was first sent to
   Daytona (two 4-CPU sandboxes); the run engineer's command quoting was wrong (the tool joins its arguments, so
   `bash -c "..."` ran a bare python3 waiting on stdin), the sandboxes idled about 2 hours each (about 16
   sandbox-CPU-hours, no output) and were interrupted and deleted; stage 2 for arm P then ran locally.
6. Arms T and M: the arrival-based supply control (uniform weights) is primary; founder-weighted beside it. Arm P:
   founder-weighted only. The prior-matched control is an exact expectation, not a draw.
7. Lambda = 1,000 has its own tail stream (Lmax = 1,000); founders are paired across doses.
8. Stage 1b: N = 200; migration into the focal slot (arm P: migrants of the resident's own program) switched off;
   equivalents grouped into classes with identical payoffs against every tester triple; 4 x 10^4 replicates per
   class. A first arm P pass had a termination bug (a resident's extinction ended the replicate as a fourth outcome
   while testers remained) and was discarded and rerun; an exploratory diverse-world version was run for arm T (arm M
   has no diverse world at N = 200).
9. Stage 3 (registered cell arm M; arm T run beside it as exploratory) adds a supply stream restricted to on-path
   equivalents of in-pair holders; the slot left out of a pair is excluded, since there every program is an
   equivalent.
10. Builds: arm P's class cache was built with parallel kernels recompiled serially (numba 0.68 fails in its parfor
    pass; the serial table is identical, and the build's own checks passed).
