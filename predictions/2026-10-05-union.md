# Predictions: the union game (2026-10-05)

Spec: `specs/2026-10-05-union.md` (reviewed by gpt-6.1-sol, `reviews/2026-10-05-union-gpt-6.1-sol.md`). Committed after
measuring only language sizes, class counts, the named programs' mutation masses and cell timings (no chain, static
table, agent-based or island output was looked at). Code: `src/union.py`, `src/union_chain.py`, `src/union_run.py`,
`src/union_abm.py`; tests `tests/test_union.py` (all pass).

## Design choices fixed before the run (the spec left these open)

- **Atoms.** Every atom is a box of a proposition about the joint action of the current encounter, on the linear GL
  chain (as `src/dollar3.py` and `src/modal.py`). Workers: `BOX(s ∈ S)` for the 6 nonempty proper subsets S of the
  wages, `BOX(h ∈ H)` for the 6 nonempty proper subsets H of the whack policies, `BOX(OTHER = work)`,
  `BOX(OTHER = strike)`, and `QUORUM = BOX(s < 1/2 → OTHER = strike)`, OTHER being the other worker of this encounter.
  Boss: `BOX(W_j = work)`, `BOX(W_j = strike)`, j = 1, 2. The wage enters through set atoms because a militant spelled
  `if(BOX(s = 1/2), work, strike)` is not provably a striker in PA (it needs ¬□, i.e. Con(PA)), and a union spelled
  with a negated wage box never resolves its Löb pair; with `BOX(s ∈ {0, 1/4})` both do (unit-tested).
- **Proof level: PA only (modalPA).** The PA + Con(PA) language has 1,802 worker functions and 585 boss functions
  (tensor 1.9·10⁹ encounters); the three-player run found modal = modalPA to three decimals. PA + Con is not run.
- **Cutoffs per role.** Boss n_B = 6, the smallest cutoff with one-atom conditionals (as the spec says: constants and
  one-atom conditionals on the workers' play; n = 6–9 give the same functions). Workers n_W = 10, the smallest cutoff
  that contains the union program `if(and(BOX(s ∈ {0,1/4}), QUORUM), strike, work)` (10 nodes). At n_W = 10 the
  two-atom functions are exactly `x if (a ∧ b) else y` and `x if (a ∨ b) else y`; no function has three atoms below
  n = 14. Prior: the length prior per role (bits = log2 a(|p|) + 2 log2 |p| + 1).
- **Union tag** (what source targeting reads): QUORUM is an essential atom of the program's canonical function. A
  spelling whose QUORUM clause is dead is the function without it and carries no tag.
- **Matched no-QUORUM arm:** the QUORUM grammar's per-spelling weights with every spelling that contains QUORUM
  removed, renormalized (so every other program keeps its relative mass). **Added arm, "blind":** the same with every
  spelling that reads the other worker (QUORUM, `OTHER = work`, `OTHER = strike`) removed; workers read only the boss.
  Reason: the measurement below shows the no-QUORUM grammar still contains a union (union′).
- **Lumping:** exact behavioural classes: a worker class is (tag, joint action against every boss and every other
  worker); a boss class its joint action against every worker pair. Payoffs follow from the joint action and the tags.
- **Summaries** (disjoint, exhaustive), in this order: *repression:strike* (strike targeting and someone strikes),
  *repression:source* (source targeting and some worker is tagged), then without whacking: *strike* (both strike),
  *scab split* (one strikes), and with both working by wage: *fair* (1/2), *intermediate* (1/4), *zero wage* (0).
- **Reduced canonical-strategy chain:** boss over the 9 constants, workers over {scab, militant, union}; mutation
  uniform over these (and, as a second column, the length prior restricted to them). Exact dense log-GTH.
- **Chain:** hybrid exploration as in the three-player run (core by log-scaled GTH, ring as stochastic complement),
  θ = 10⁻⁹, seeded with every (boss constant) × (scab, always strike, militant, union, union′)² triple. w = 0.3.
- **Agent-based runs:** N = 100 per slot, εN = 0.1 per slot per generation, 10⁵ generations, 3 seeds, starts low-wage
  ((0, none), scab, scab) and fair ((1/2, none), union, union); at c = 0.5 first (prediction 5), then c = 0 and 0.1.
  "Phase" = summary of the triple of majority classes when every slot has one, else "mixed".
- **Spatial selection on bosses:** I = 16 islands of N = 100 per slot, complete graph, mN = 1 per slot per island,
  εN = 0.1 per slot per island per generation, w = 0.3; per birth with probability m = 1/N the parent comes from
  another island drawn with weight exp(w_g[slot] · mean payoff of that slot on the island) (`src/islands.py`
  operator, per slot). Conditions: w_g = 0; w_g^B = 10 (boss slot only); w_g = 10 on all slots. 3 seeds each, all
  islands start low-wage. c = 0.5 (prediction 4) first, then c = 0 if time allows. The generation count is set from a
  timing run so that each run takes at most about 1.5 hours, and is stated in the results.

Two facts from the measurement that bear on the predictions:
- **union′ is the union.** `BOX(s<1/2) ∧ BOX(s<1/2 → OTHER strikes)` is equivalent to `BOX(s<1/2) ∧ BOX(OTHER strikes)`
  in GL, so union and union′ play identically in every encounter (tested over the whole tensor), at the same size and
  mass. union′ carries no tag. So the matched no-QUORUM arm still contains a union; only source targeting can tell
  the two apart. This is the "semantically equivalent union implementation without the atom" the spec asked to test.
- **The union is a 2-atom program at mass 10⁻⁵, 120× rarer than the militant** and 5·10⁴× rarer than the scab.

## RE predictions (Fable, from the spec, verbatim in substance)

1. **The fair state is not drift-closed; it leaks through the scab** (scab neutral at 1/N in a worker slot, then a
   strict wage cut). *Falsifier:* a fair state with no neutral exit, or an exit slope steeper than −1.3.
2. **The low-wage states leak back through the union; the quorum matters only at the intermediate wage.** At
   c = 0.5 the chain alternates among fair, intermediate and zero-wage states with transitions ∝ 1/N; the fair share is
   N-independent within 2× over N = 10²–10⁴ and lies in [0.2, 0.6]; the intermediate state holds at least 0.2.
   *Falsifier:* fair share below 0.1 or above 0.8 at N = 10⁴, c = 0.5, or changing by more than 3× over N.
3. **Repression wins the drift race more often at lower c.** The fair share is monotone in c: at c = 0 below 0.15, at
   c = 0.1 below the c = 0.5 value by at least 0.1; the repression share is the mirror image. *Falsifier:* fair share at
   c = 0 above the c = 0.5 value.
4. **Spatial selection on bosses lowers the fair share:** with w_g^B = 10 the time in the fair state falls by at least
   0.15 relative to w_g = 0 at c = 0.5; with w_g on all slots the effect is smaller. (Sol's alternative: migration
   spreads cheap exploitation rather than pre-emptive repression; the joint (s, whack) distribution across islands
   decides.) *Falsifier:* w_g^B = 10 raising the fair share by more than 0.05.
5. **Finite ε:** from the low-wage start the first fair phase appears within 10⁴ generations in all seeds at c = 0.5,
   and phases alternate with dwell 10²–10⁴ generations. *Falsifier:* no fair phase in 10⁵ generations in 2 of 3 seeds.
6. **Without the quorum the chain settles at the intermediate wage:** in the matched no-QUORUM grammar the intermediate
   state holds at least 0.5 of π and the fair state at most 0.15 at every c; with QUORUM the fair share is higher by at
   least 0.2 at c = 0.5. *Falsifier:* the no-quorum arm's fair share within 0.1 of the quorum arm's, or its
   intermediate share below 0.3.

## RS predictions (Jacob, from chat 2026-10-04, via the spec)

- With public membership, "whack any union member" strangles the union; the union would work with private membership
  (not realizable here). Here membership is public (the tag is in the source), so this predicts that source
  targeting suppresses the union. Operationalized: in the QUORUM arm, the π mass of states with a tagged worker is
  lower at c = 0 than at c = 0.5, and source targeting holds positive mass wherever the union does.

## Subagent addenda (made before the run, from the measured masses and the static algebra; not the RE's)

These come from working the payoffs by hand before any table was computed. At s = 1/4 a *second* union strikes and
earns 0 against a scab's 1/4, so it is deleterious; the union is neutral only at s = 0, where every worker program
earns 0 unless whacked (so `strike` and the militant are neutral there too). Source targeting cannot see union′ or the
militant.

- A1. The intermediate state is transient: its share is below 0.05 at every (c, N) in every arm.
- A2. The fair share is below 0.1 at every (c, N) in the QUORUM arm (prediction 2's falsifier fires), because the
  worker slots at s = 0 drift mostly among scab and always-strike (mass 0.48 each) while union and militant are rare.
- A3. The QUORUM, no-QUORUM and blind arms have fair shares within 0.02 of each other at every (c, N) (the union's
  mass is too small to move π, and the militant, present in all three, carries what union-like mass there is).
- A4. Realized source-targeting repression holds less than 0.01 of π at every (c, N).
- *Falsifiers:* any of the stated bounds broken.
