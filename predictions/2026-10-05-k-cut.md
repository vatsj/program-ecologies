## Design choices fixed before the run

1. **The calculus.** K_c = K + Cut + UnfId + Dist_k (k ≤ 3) (notes §1.4); Dist is primitive because of Theorem D0.
   The search explores Cut in the form the soundness proof uses it (Lemma C lemma cuts on Dist hypotheses' contents,
   the MP values); general contextual cut is not searched, so computed minimal sizes are **upper bounds** on K_c's.
   Exactness of a table cell is established by the certificate: if every GL-true content the search misses at b is
   certified structural, the computed table is K_c's table. Uncertified misses are reported with their count and
   μ-weight. The counted arm for every RE verdict is K_c at K's guard convention (g = 0).
2. **Structural vs cost (spec item 2).** For every named atom not derivable at b = 54, the extension-model certificate
   at each b from 4 to 200 (a certificate covers every size at that b). Any named atom left uncertified gets the
   spec's capped search (family closure, cap up to 200). "Structural" = certified, or not derivable at any b ≤ 200.
3. **Faker sets for RE 2.** The repo has no class list of "22 Con sentences" (in "K with the 4-rule" 22 is a count of
   misclassified *pairs*). Operationalized as: **Gödel set** = the 21 Gödel-flagged classes of
   `runs/k-at-n8-fakers.json`; **Con set** = its 16 other K-disarmed classes (probe readers of Gödel and Con sentences).
   RE 2's Con thresholds are scaled proportionally: restored ≥ 8 of 16 (held), ≤ 3 (falsifier), 4–7 grey. A faker is
   **restored** at b if it strictly invades (U[z, x] > U[x, x]) a fixed-panel victim in the arm's table at b and not in
   K's. Fixed panel: FairBot, `BOX1(THEM(ME))`, PrudentBot, P\*, `BOX(THEM(THEM))` (their self-play in each arm is
   reported, since P\* self-defects in K); endogenous panel: the arm's supported self-cooperators (π ≥ 10⁻³ at N = 10⁴).
   Hazards both as source counts and μ-weighted.
4. **Tables.** n = 6 at b ∈ {4, 16, 40}; n = 8 at b ∈ {4, 8, 16, 24, 54} (plus 32 if time allows), GL-erasure prune,
   K's JLöb candidate rule, plain + closure soundness checker, the certificate on every miss, and the independent
   checker with witness replay on every derived content at n = 6 and on a 2,000-content sample at n = 8.
5. **Leak tests** at fixed b and on the cross-budget catalogue {4, 16}.
6. **Chains** with an audited log-domain solver: `src/chain_log.py` is not on this branch, so `src/k_cut.py` carries a
   seeded log-domain solve on the same transition model as `chain.Chain` (every monomorphic state and every
   discovered polymorphic state expanded, log-domain GTH on the closed class), independent state discovery (a closure
   exploration from all monomorphic seeds, compared with the lazy exploration's state set), twin drift reported,
   residual ‖πQ‖ and a rate-level validation (dominant entry/exit fixation probabilities recomputed by a direct Moran
   sum). If a K_c table is identical to K's, its chain is K's chain (same matrix) and is reported as such.
7. **2×2 restoration (spec item 4).** Frozen at b = 16 on the full n = 8 catalogue: R_coop = classes self-cooperating in
   K_c but not K; R_expl = classes strictly invading a fixed-panel victim in K_c but not K. Hybrids replace rows and
   columns of R_coop / the (invader, victim) and (victim, invader) entries of R_expl from K_c's table into K's; each
   entry's source table is recorded and checked. Solved at N = 10⁴. If both sets are empty the design is degenerate
   (all four cells are K) and RE 3 is untestable.
8. **Factorial (spec item 5).** K / K_c × g = 0 / g = 1 at b = 16, N = 10⁴; interaction = (K_c,1) − (K_c,0) − (K,1) + (K,0).
9. **Lottery.** K_c at b = 16, (100, 64), mN = 1, 20 paired seeds (seeds shared with "K at n = 8"); success = every
   island held by a self-cooperator at the end (the almost-all-seeds outcome rule), censored = unresolved.
10. **Exploratory arms (outside every RE verdict):**
    *K_c + 4m* (4m composed with cut and Dist) in the sweeps and at n = 8, b = 16, 54;
    *the long-guard arm* **K_c4 with the guard read at 2b + 8** (g = b + 8; notes §1.9), the only setting in this family
    where Con-dependent cooperation can return: named-family sweep b = 4…54, n = 8 table at b = 16 (and 54 if time
    allows), restored cooperators and fakers, chain at b = 16. It re-opens REJECTED's "the 4-rule re-arms PB2 and the
    level-2 ladder" in the direction that entry names ("a different guard convention or a calculus with distribution"),
    on the new evidence of Lemma E1 (the guard budget gap is what binds).

   effect; the RE does not predict an ordering of the main effects (sol's point adopted). *Falsifier:* interaction

## Verdict rules

A prediction **holds** if no clause's falsifier fires and every clause's main statement is met; **fails** if any
clause's main statement is not met; the verdict notes whether the explicit falsifier fired. Grey zones are
**inconclusive**. A prediction whose quantity cannot be formed (for RE 3, a design with both main effects 0) is
**untestable**, reported as such, not as held. Exploratory arms never decide an RE verdict; their numbers are reported
next to the RE verdicts they bear on.
